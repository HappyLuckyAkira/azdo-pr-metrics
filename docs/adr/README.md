# ADR（設計判断の記録）

このツールの設計で「なぜそうしたか」を、1 つの判断につき 1 ファイルで記録する。

- 判断を変えるときは、元の ADR を書き換えずに新しい ADR を作り、元の ADR の「状態」を「置き換え（ADR-xxxx）」にする。
- 古い設計判断（D-01〜D-09）は `docs/02_基本設計.md` の 5 章にある。今後の判断はここに追加し、02 の 5 章には要点とリンクだけを書く。
