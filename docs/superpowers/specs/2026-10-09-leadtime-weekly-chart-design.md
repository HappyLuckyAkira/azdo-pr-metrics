# 仕様書: クローズまでの時間別 PR 件数の週次折れ線グラフ

- 作成日: 2026-10-09
- 状態: 合意済み（実装前）

## 1. 目的

PR がマージされるまでにかかった時間の傾向を、週ごとの推移として見られるようにする。
「24 時間未満で閉じた PR」「24〜72 時間かかった PR」「72 時間以上かかった PR」の件数を 3 本の折れ線にし、レビューの滞留が増えていないかを確認する。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 集計範囲 | 可変。既存の `FromDate` / `ToDate` / `LastNDays`（設定・引数）をそのまま使う |
| 横軸 | **週単位で固定**（既存の `PeriodUnit` とは無関係）。週の始まりは既存の `WeekStartDay`（既定: 月曜） |
| 加算する週 | PR の**完了日時**（設定タイムゾーン、既定: 日本時間）が属する週 |
| 対象 PR | 既存の絞り込みを通った PR のうち、**status = completed（マージ済み）** で完了日時があるもの。`Statuses` に `abandoned` があっても数えない |
| 区分 | **固定の 3 区分**（設定で変更しない）。下表 |
| 端の週 | 範囲を変えずに集計し、7 日に満たない週は**注記**する |
| 出力形式 | **HTML**（グラフはツールが SVG で直接描く。外部ライブラリ・外部通信なし） |
| 作り方 | **既存の実行（`Invoke-PrMetrics.ps1`）に組み込む**（案 A） |
| 設定項目 | **追加しない** |

### 2.1 区分

クローズまでの時間 ＝ 完了日時 − 作成日時（既存の `LeadTimeHours` と同じ。Draft の期間も含む）

| 区分 ID | 表示名 | 条件 |
|---|---|---|
| `Under24h` | 24時間未満 | 0 ≤ 時間 < 24 |
| `From24To72h` | 24〜72時間未満 | 24 ≤ 時間 < 72 |
| `Over72h` | 72時間以上 | 72 ≤ 時間 |

境界ちょうど（24.00 / 72.00）は上側の区分に入る。

### 2.2 DateBasis との関係

`DateBasis = 'Closed'`（既定）のときだけグラフを作る。`'Created'` の場合は「範囲内に作成された PR を完了週で数える」ことになり意味がずれるため、グラフとその CSV は作らず警告を表示する（既存の出力には影響しない）。

### 2.3 複数リポジトリ

リポジトリごとに集計・グラフ化する。リポジトリが 2 つ以上なら `(ALL)` も作る（既存の `Get-RecordGroups` と同じ規則）。

## 3. 出力

出力フォルダ `{OutputDir}\yyyyMMdd_HHmmss\` に次の 2 ファイルを追加する。

### 3.1 `summary_leadtime_weekly.csv`

UTF-8（BOM 付き）。（リポジトリ × 週）＝ 1 行。範囲内のすべての週を出力する（0 件の週も含む）。

| 列 | 例 | 説明 |
|---|---|---|
| `Repository` | `SampleRepo` | リポジトリ名 または `(ALL)` |
| `WeekStart` | `2026-09-28` | 週の開始日 |
| `WeekEnd` | `2026-09-30` | 週の最終日。範囲で切れる場合は範囲の最終日 |
| `Days` | `3` | 週のうち範囲に含まれる日数（1〜7） |
| `IsPartial` | `True` | `Days < 7` |
| `Under24h` | `5` | 24 時間未満の件数 |
| `From24To72h` | `3` | 24〜72 時間未満の件数 |
| `Over72h` | `1` | 72 時間以上の件数 |
| `Total` | `9` | 3 区分の合計 |

### 3.2 `leadtime_chart.html`

UTF-8 の単一 HTML ファイル。外部リソースを読み込まない。

- **見出し**: 対象リポジトリ、集計範囲、条件（マージ済み PR・完了日で週に集計）、作成日時
- **折れ線グラフ**（リポジトリごとに 1 つ、SVG）
  - 横軸: 週の開始日（`MM/dd`）。週が多いときはラベルを間引いて重ならないようにする
  - 縦軸: 件数（0 始まり、整数の目盛り）
  - 3 本の線。色と点の形を変える（白黒印刷でも区別できるように）
    - 24時間未満: 緑・丸
    - 24〜72時間未満: オレンジ・四角
    - 72時間以上: 赤・三角
  - 凡例を表示する
  - 端の週（`IsPartial`）: 点を白抜きにし、横軸ラベルに `*` を付け、グラフの下に「* 09/28 の週は 3 日分」と注記する
  - 各点に SVG の `<title>` を付け、マウスを重ねると「09/28 の週 24時間未満: 5件」と表示する
- **表**: グラフの下に CSV と同じ数値の表
- 対象 PR が 0 件のとき: 0 件の線を描き、「対象の PR がありません」と表示する（エラーにしない）
- HTML に埋め込む文字列（リポジトリ名など）はエスケープする

## 4. 構成

### 4.1 新規ファイル `src/LeadTimeChart.ps1`

| 関数 | 役割 | 入力 → 出力 |
|---|---|---|
| `Get-LeadTimeBucket` | 時間を区分 ID に振り分ける | 時間（数値） → `Under24h` / `From24To72h` / `Over72h` |
| `Get-LeadTimeWeeklySummary` | 週 × 区分の件数を集計（0 件の週・端の週の日数を含む） | 明細レコード・設定・範囲 → 3.1 の行の配列 |
| `New-LeadTimeChartSvg` | 1 グループ分の折れ線グラフを SVG 文字列で作る | 3.1 の行（1 グループ分） → SVG 文字列 |
| `New-LeadTimeChartHtml` | 見出し・グラフ・注記・表をまとめた HTML を作る | 集計結果・設定・範囲 → HTML 文字列 |

- 週の計算は既存の `Get-PeriodStart` / `Get-PeriodStarts`（Unit = `Week` を固定で渡す）、グループ分けは既存の `Get-RecordGroups` を使う。
- グラフ関数は文字列を返すだけで、ファイルには書き出さない（テストしやすくするため）。
- 明細レコードの `Status` と `LeadTimeHours` を使う。週は明細レコードの `ClosedAt`（設定タイムゾーンでの `yyyy-MM-dd HH:mm`）から求める。

### 4.2 既存ファイルの変更

| ファイル | 変更 |
|---|---|
| `Invoke-PrMetrics.ps1` | `LeadTimeChart.ps1` を読み込む。既存 CSV の出力後に、`DateBasis='Closed'` なら週次集計 → CSV → HTML を出力。そうでなければ警告 |
| `src/Output.ps1` | HTML を UTF-8 で書き出す関数を追加（既存の JSON 出力と同様） |
| `tests/Run-Tests.ps1` | `LeadTimeChart.ps1` を読み込み、テストを追加 |

### 4.3 処理の流れ

```
既存の CSV 3 種を出力
  ↓
DateBasis = 'Closed' ?
  ├ No  → 警告「グラフは DateBasis='Closed' のときだけ作成します」→ 以降は既存どおり
  └ Yes → Get-LeadTimeWeeklySummary → summary_leadtime_weekly.csv
                                    → New-LeadTimeChartHtml → leadtime_chart.html
```

`-ReplayDir` 実行時も同じ流れでグラフを作る。

## 5. エラー処理

- グラフ・週次 CSV の作成で例外が起きた場合は、警告を表示して処理を続ける（既存 CSV は先に出力済みなので失われない）。
- 終了コードは既存どおり（グラフの失敗だけでは 1 にしない）。

## 6. テスト

`tests/Run-Tests.ps1` に追加する（PowerShell 5.1 / 7 の両方で全件成功させる）。

| 分類 | 確かめること |
|---|---|
| 区分 | 0 → Under24h、23.99 → Under24h、24 → From24To72h、71.99 → From24To72h、72 → Over72h |
| 対象 | abandoned・完了日時なしは数えない |
| 週 | 0 件の週も行がある。範囲 9/3（木）〜9/30（水）で最初の週 `Days=4`・`IsPartial=True`、最後の週 `Days=3`。日曜 23:30（日本時間）完了は同じ週 |
| グループ | リポジトリ 2 つで `(ALL)` の行がある |
| SVG | 折れ線が 3 本、端の週の点が白抜き、週が多いとラベルが間引かれる |
| HTML | 見出し・注記・表がある。`<`・`&` がエスケープされる。0 件で「対象の PR がありません」 |
| DateBasis | `Created` のときグラフを作らない |

加えて、模擬データで通し実行し、生成した HTML をブラウザで開いて見た目を確認する。
