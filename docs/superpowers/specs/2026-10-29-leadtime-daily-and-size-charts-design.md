# 仕様書: クローズまでの時間別グラフに「日単位」と「サイズ別（大・中・小）」を追加

- 作成日: 2026-10-29
- 状態: 合意済み（実装前）
- 前提: [2026-10-09 週次グラフの仕様書](2026-10-09-leadtime-weekly-chart-design.md)（実装済み）

## 1. 目的

既存の「クローズまでの時間別 PR 件数（週次）」グラフを、次の 2 つの観点で見られるようにする。

1. **日単位**: 週より細かい粒度での推移
2. **サイズ別**: PR の大きさ（大・中・小）とクローズまでの時間の関係（例: 大きい PR ほど 72 時間以上かかっていないか）

サイズは既存の `SizeCategory`（XS〜XL）を使う。新しいサイズの計算は行わない。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| グラフの数 | 全体・大・中・小 × 週単位・日単位 ＝ **8 つ**（リポジトリごと） |
| 並び順 | **サイズごと**: 全体（週 → 日）→ 大（週 → 日）→ 中（週 → 日）→ 小（週 → 日） |
| 大・中・小の定義 | 既存の区分をまとめる: **小 = XS・S / 中 = M / 大 = L・XL**（区分名で対応づける） |
| グラフの形 | 週・日とも、既存と同じ**折れ線**（3 本: 24時間未満 / 24〜72時間未満 / 72時間以上）。日単位の表し方は [ADR-0002](#61-adr) |
| 縦軸 | 大・中・小は**同じ目盛り**（週は週どうし、日は日どうし）。全体は別の目盛り |
| サイズ不明の PR | 全体には含め、大・中・小には含めない。件数を注記する。全件サイズ不明なら大・中・小の代わりに案内を出す（[ADR-0001](#61-adr)） |
| CSV | 既存の週次 CSV に `SizeGroup` 列を追加。日次 CSV を新規作成（案 A） |
| 表 | 開閉式（`<details>`）で、最初は閉じておく |
| 設定項目 | **追加しない** |
| 変わらないもの | 対象（マージ済みのみ）、区分の境界（24・72 時間、境界は上側）、`DateBasis='Closed'` のときだけ作る、外部リソースなし、失敗しても警告して続行 |

### 2.1 大・中・小

| 区分 ID | 表示名 | 元の区分（`SizeCategory`） | 既定の閾値: 行数（Git 方式） | 既定の閾値: ファイル数（Api 方式） |
|---|---|---|---|---|
| `Large` | 大 | L, XL | 251 行〜 | 11 ファイル〜 |
| `Medium` | 中 | M | 51〜250 行 | 4〜10 ファイル |
| `Small` | 小 | XS, S | 〜50 行 | 〜3 ファイル |

- 対応は区分名で決める。閾値は既存の `SizeCategories` 設定に従うので、設定を変えれば大・中・小の範囲も変わる。
- 見出しの範囲表示（例「大（L・XL：251行〜）」）は `SizeCategories` の `MaxLines`（Api 方式なら `MaxFiles`）から作る。`SizeMethod` が `Git` なら行数、`Api` ならファイル数で表示する。
- `SizeCategory` が空、または XS/S/M/L/XL 以外の名前の PR は「サイズ不明」。

### 2.2 日単位

- 完了日時（設定タイムゾーン）の**日付**で数える。範囲内のすべての日を出す（土日・0 件の日も含む）。
- 日単位には「部分的な期間」は無い（端の注記は週単位だけ）。
- 横軸ラベルは週単位と同じく最大 12 個に間引く（`ceil(日数/12)` 日おき）。形式は `MM/dd`。
- 点のツールチップは「09/28 24時間未満: 2件」（週単位は従来どおり「09/28 の週 24時間未満: 2件」）。

### 2.3 サイズ不明の PR

- 次の PR は大・中・小のどれにも入れない（全体には入れる）:
  - `SizeMethod = 'None'` で実行したとき（全件がサイズ不明）
  - サイズ計算に失敗した PR（`SizeSource = 'unavailable'`）
  - `SizeCategory` が XS/S/M/L/XL 以外
- 小のグラフの後に「※ サイズ不明の N 件は、サイズ別（大・中・小）のグラフに含まれていません（全体には含まれます）。」と表示する（N = 0 のときは表示しない）。
- 全体が 1 件以上あり、大・中・小がすべて 0 件のとき（全件サイズ不明）は、大・中・小のグラフを描かずに「サイズを計算していないため、サイズ別のグラフは表示できません（`SizeMethod` を `Git` または `Api` にして実行してください）。」と表示する。
- 決定の理由と代替案は ADR-0001 に記録する。

行の並び: リポジトリ → `SizeGroup` → 日付の昇順。

### 3.3 `leadtime_chart.html`（既存・構成を変更）

```
見出し: 「クローズまでの時間別 PR 件数」、組織/プロジェクト、集計範囲、週の始まり、対象、作成日時
（リポジトリごとに）
  <h2>リポジトリ名</h2>
  凡例（1 回）
  <h3>全体（N件）</h3>             … 0 件なら「対象の PR がありません」
     <h4>週単位</h4> グラフ ＋ 端の週の注記
     <h4>日単位</h4> グラフ
  <h3>大（L・XL：251行〜）（N件）</h3>
     週単位 ＋ 注記 ／ 日単位
  <h3>中（M：51〜250行）（N件）</h3>
     週単位 ＋ 注記 ／ 日単位
  <h3>小（XS・S：〜50行）（N件）</h3>
     週単位 ＋ 注記 ／ 日単位
  ※ サイズ不明の注記（N > 0 のとき）
  （全件サイズ不明のときは、大・中・小の 3 つの代わりに案内を 1 つ）
  <details> 数値の表（週単位）</details>   … 列: 週の開始日, 期間, 日数, 区分(全体/大/中/小), 3 区分, 合計
  <details> 数値の表（日単位）</details>   … 列: 日付, 区分, 3 区分, 合計
```

- 縦軸の上限: 週単位の大・中・小は、その 3 つの週次データの最大値から決めた同じ上限を使う。日単位も同様。全体は自分のデータだけで決める。
- 見た目（色・点の形・白抜き・ツールチップ・ラベルの間引き）は既存の週次グラフと同じ。

## 4. 構成

すべて `src/LeadTimeChart.ps1` 内で変更する（新規ファイルなし）。

| 関数 / 定義 | 種別 | 内容 |
|---|---|---|
| `$script:LeadTimeSizeGroups` | 新規 | 大・中・小の定義。`[pscustomobject]@{ Id; Label; Categories }` の配列（順序: Large, Medium, Small） |
| `Get-LeadTimeSizeGroup -SizeCategory` | 新規 | `'Large'` / `'Medium'` / `'Small'` / `''`（不明） |
| `Get-LeadTimeSizeGroupRangeText -Group -Config` | 新規 | 見出しの範囲表示（例 `L・XL：251行〜`）を `SizeCategories` と `SizeMethod` から作る |
| `Get-LeadTimeWeeklySummary` | 変更 | `SizeGroup` 列を追加し、All/Large/Medium/Small の行を作る |
| `Get-LeadTimeDailySummary` | 新規 | 日単位の同じ集計（3.2 の行） |
| 集計の共通部 | 新規（内部） | 週次・日次で重複しないよう、「対象の絞り込み → 期間キーごとの件数の数え上げ」を共通の内部関数にする |
| `New-LeadTimeChartSvg` | 変更 | `-Unit Week|Day`（ラベル・ツールチップの文言、日付列の選択）と `-YMax`（0 = 自動）を追加。既定値は従来どおりの動作 |
| `$script:LeadTimeChartStyles` / `New-LeadTimeChart` | 新規 | **グラフの描き方を 1 か所で決める**仕組み。`@{ Week = 'Line'; Day = 'Line' }` の対応表と、それに従って描画関数を選ぶ `New-LeadTimeChart -Rows -Unit -YMax`。HTML は描画関数を直接呼ばず、必ずこれを通す（[6.2](#62-日単位グラフの表し方を変えるための準備)） |
| `$script:LeadTimeDailySizeGroups` | 新規 | 日単位のグラフを出す区分の一覧。既定 `@('All', 'Large', 'Medium', 'Small')`（[6.2](#62-日単位グラフの表し方を変えるための準備)） |
| `New-LeadTimeChartHtml` | 変更 | `-WeeklySummary` と `-DailySummary` を受け取り、3.3 の構成で出力 |

`Invoke-PrMetrics.ps1` は、日次集計と `summary_leadtime_daily.csv` の出力を追加し、HTML に週次・日次の両方を渡す。

| 案 | 内容 | 主な変更 |
|---|---|---|
| A | 日単位を積み上げ棒グラフにする | 棒グラフの描画関数 `New-LeadTimeBarChartSvg` を追加し、`$script:LeadTimeChartStyles.Day = 'Bar'` にする |
