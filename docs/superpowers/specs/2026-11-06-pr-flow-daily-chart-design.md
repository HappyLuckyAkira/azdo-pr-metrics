# 仕様書: PR の作成数・滞留数・Close 数の日次棒グラフ

- 作成日: 2026-11-06
- 状態: 合意済み（実装前）
- 前提: [2026-10-29 日単位・サイズ別グラフの仕様書](2026-10-29-leadtime-daily-and-size-charts-design.md)（実装済み）

## 1. 目的

日ごとに「PR がいくつ作られ、いくつ閉じられ、いくつ溜まっているか」を見られるようにし、レビュー待ちの PR が溜まっていないかを把握する。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 集計単位 | **日単位**（設定タイムゾーンの日付。範囲内のすべての日、0 件の日も含む） |
| グラフ | 1 日につき **3 本の棒（作成・滞留・Close）を並べた棒グラフ**。日と日の間に**空白**を入れる |
| 置き場所 | `leadtime_chart.html` の各リポジトリの**最後**（数値の表の後）。**全体だけ**（サイズでは分けない） |
| データ | **追加取得（案 A）**。既存の取得・出力は変えない |
| 作られる条件 | `leadtime_chart.html` と同じく `DateBasis = 'Closed'` のときだけ |
| 設定項目 | 追加しない |

### 2.1 数え方

| 棒 | ID | 定義 |
|---|---|---|
| 作成 | `Created` | その日に作成された PR の数（状態を問わない） |
| 滞留 | `Open` | その日の終わり（翌日 0:00）の時点で、作成済みでまだクローズされていない PR の数。範囲より前に作られて開いたままの PR も含む |
| Close | `Closed` | その日にクローズされた PR の数（マージ `completed` と破棄 `abandoned` の両方） |

- 毎日 **滞留（当日）＝ 滞留（前日）＋ 作成（当日）− Close（当日）** が成り立つ。
- 同じ日に作成・クローズされた PR は、作成と Close に 1 ずつ数え、滞留には入らない。
- 対象の PR には既存の絞り込みのうち **Draft の除外・マージ先ブランチ・除外する作成者** を適用する（期間の絞り込みは使わない）。Draft は PR の現在の状態で判定する。

### 2.2 データの取得（案 A）

グラフを作るときだけ、リポジトリごとに次を追加で取得する。

1. いま開いている PR（`status=active`）: 期間の指定なしで全件
2. 集計範囲の開始時点以降にクローズした PR（`status=completed` と `abandoned`）: クローズ日時が開始時点以降（上限は実行時点）。`UseServerSideDateFilter=$false` の場合は全件取得してツール側で数える

同じ PR 番号は 1 件にまとめる。この 2 つで「範囲内のどこかの日に開いていた PR」と「範囲内に作成・クローズされた PR」をすべて含む。

- `SaveRawJson=$true` のとき `raw_pullrequests_flow_{リポジトリ}.json` に保存し、`-ReplayDir` 実行時はそれを読む（無ければこのグラフだけ作らない）。

## 3. 出力

### 3.1 `summary_pr_flow_daily.csv`（新規）

UTF-8（BOM 付き）。（リポジトリ × 日）＝ 1 行。リポジトリが複数のときは `(ALL)` の行も出す。

| 列 | 例 | 説明 |
|---|---|---|
| `Repository` | `SampleRepo` | リポジトリ名 または `(ALL)` |
| `Date` | `2026-09-28` | 日付 |
| `Created` | `3` | 作成数 |
| `Open` | `12` | 滞留数（その日の終わり） |
| `Closed` | `4` | Close 数（マージ＋破棄） |

### 3.2 `leadtime_chart.html`（追記）

各リポジトリの最後に次を追加する。

```
<h3>PR の作成・滞留・Close（日単位）</h3>
定義の説明（1 行）
凡例（作成・滞留・Close の色）
棒グラフ（SVG）
<details> 数値の表（PR の作成・滞留・Close）</details>
```

- 棒の並びは各日 **作成 → 滞留 → Close**（左から）。色は既存の折れ線と区別できる 3 色（作成 `#1565c0`・滞留 `#8e24aa`・Close `#00897b`）。並び順が固定なので白黒でも区別できる。
- 1 日の枠のうち 75% に 3 本の棒を隙間なく並べ、残り 25% を日と日の間の空白にする。
- 横軸は日付（`MM/dd`）、最大 12 個に間引く。縦軸は 0 始まりの整数目盛り。
- 各棒に `<title>`（例「09/28 滞留: 12件」）。
- 追加取得に失敗した・Replay 用ファイルが無いときは、見出しの下に「PR の作成・滞留・Close のデータを取得できなかったため、このグラフは表示できません。」と表示する。

## 5. エラー処理・テスト

- 追加取得の失敗は警告にし、他の出力は通常どおり作る（HTML には 3.2 の「表示できません」）。

- 模擬データで通し実行し、ブラウザで見た目を確認する。
